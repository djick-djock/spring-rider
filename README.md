# Spring Rider

Squishy-suspension motocross across four worlds and 48 levels. Grab every apple, then touch the flower — and keep your head off the ground.

**Play:** https://djick-djock.github.io/spring-rider/ — on Android, open it in Chrome and choose **⋮ → Install app** for a fullscreen, offline home-screen app.

| Key | Action |
|---|---|
| ↑ / W | Throttle |
| ↓ / S | Brake |
| ← → / A D | Tap to volt, hold to lean |
| Space | Turn around |
| Enter | Restart level |
| Esc | Level select |
| M / F | Sound / fullscreen |

On touch screens, on-screen buttons appear automatically.
